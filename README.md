# Uthai Nutrition — Review Demo

This repository contains **compiled static website assets only** for sharing a demo with dietetics colleagues.

- **Not a clinical system.** Use mock data only; never enter actual patient identifiers or treatment information.
- The private development repository is retained separately.
- Browser localStorage contains demo order changes; there is no backend or hospital data connection.
- The calculation module requires clinician-provided factors. It does not implement verified PROTAI clinical logic.
- Published for UI/workflow feedback, not clinical decisions.

Deployment: GitHub Pages from main branch / (root).
